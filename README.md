 Weather App

A weather application built using HTML, CSS, JavaScript, and the Open-Meteo API.

 Features

 Search weather by city name
 View temperature, humidity, wind speed, and weather conditions
 Search using button or Enter key
 Loading state and error handling
 Deployed using GitHub Pages

 Tech Stack

HTML • CSS • JavaScript • Open-Meteo API • GitHub Pages

Interview Quick Revision

1. What is this project?**
A web app that displays current weather for a searched city.

**2. Why did you build it?**
To practise JavaScript, API integration, and DOM manipulation.

**3. What is an API?**
A way for two software systems to communicate.

**4. Which APIs did you use?**
Open-Meteo Geocoding API and Forecast API.

**5. Why two API requests?**
First, get the city's latitude and longitude; then fetch its weather.

**6. What is `fetch()`?**
A JavaScript function used to make network requests.

**7. What are `async/await`?**
A way to write asynchronous code more clearly.

**8. What is JSON?**
A format for exchanging structured data.

**9. What is DOM manipulation?**
Accessing or updating webpage elements using JavaScript.

**10. What is an event listener?**
Code that responds to events like clicks or key presses.

**11. How do you handle errors?**
Using `try/catch`, response status checks, and user-friendly messages.

**12. What does HTTP 404 mean?**
The requested resource was not found.

**13. What is `finally` used for?**
To run cleanup code whether the request succeeds or fails.

**14. How is the app deployed?**
Using GitHub Pages from the `main` branch and root folder.

**15. What did you learn?**
API integration, asynchronous JavaScript, debugging, and deployment.

**16. What would you improve next?**
Add a multi-day forecast, better mobile design, and more features.
